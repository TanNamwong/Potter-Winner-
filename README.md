# PotterWinner Trail Run

เกมวิ่งแนวนอน เล่นบนเบราว์เซอร์/มือถือ ติดตั้งเป็น PWA ได้

## วิธีเล่น
- **แตะหน้าจอ** หรือกด **Space / ↑ / W** เพื่อกระโดด (กระโดดซ้อนได้ 2 ครั้ง)
- **P / Esc** หรือปุ่ม ⏸️ เพื่อพักเกม (พักอัตโนมัติเมื่อสลับแอป)
- เก็บเหรียญ 🪙 ระหว่างทาง

## โหมด
- 🛡️ **Sandbox** – ไม่มีสิ่งกีดขวาง ไม่ตาย ปรับสปีดได้ 1–15x
- 🏆 **ปกติ** – ชนครั้งเดียวจบ ยิ่งไกลยิ่งเร็ว เก็บสถิติสูงสุดไว้ในเครื่อง
- 🗺️ **ผจญภัย** – วิ่งให้ครบ 1000 เมตร มี 3 ชีวิต

## รันในเครื่อง
Service Worker ต้องเปิดผ่าน http(s) เช่น `python3 -m http.server` แล้วเข้า http://localhost:8000
(การเปิดไฟล์ตรงๆ แบบ file:// เล่นเกมได้ แต่ติดตั้ง PWA ไม่ได้)
